## 📖 About the Project

This project demonstrates how to use SOAP API in combination with Express. It involves creating an Express server that communicates with a SOAP-based web service to fetch data about countries. The application makes multiple requests to the SOAP API to retrieve the country name, capital, currency, and flag, and exposes these data through an Express endpoint.


## 🛠️ Tools Used

**JavaScript** (ES Modules).
**Express** (Server framework).
**SOAP** (To interact with the SOAP ).
**nodemon** (For hot-reloading during development).


## 📋 Prerequisites

Before you begin, make sure you have:

## 🚀 Project Usage

### 1. Clone the Repository
```bash
git clone https://github.com/EAllaucaD/soap_app.git
```
### 2. Commands

You need to run the following commands
```
    npm install -y
```

```
    npm install soap express nodemon

```


### 3. Execute
Once you open the files and run the necessary commands, you can use the following command to run the application.

```
    npm start
```
You can view the execution of the application on the port http://localhost:2000/

You can see the information of Ecuador.
